## Diretrizes de Commit e Pull Request
### Commits semanticos (PT-BR)
- Use este formato com icone e descricao em Portugues:
  - `<icone> Queryable - <categoria>: <descricao>`
- Nao incluir linha de co-autoria (Co-authored-by) em commits.
- Categorias aceitas:
  - `chore` (🧹), `feat` (✨), `bugfix` (🐛), `docs` (📚), `test` (🧪), `build` (⚙️), `ci` (🔧), `deps` (📦), `perf` (🚀), `remove` (🔥), `style` (🎨), `refactor` (♻️)
- Exemplos:
  - `🧹 Queryable - chore: Criar Seeders`
  - `✨ Queryable - feat: Cadastro de usuario`
  - `🐛 Queryable - bugfix: Resolvendo problema de autenticacao`
  - `📚 Queryable - docs: Atualizando guia de usuario`
  - `🧪 Queryable - test: Criar testes de integracao para autenticacao`
  - `⚙️ Queryable - build: Ajustar pipeline de build`
  - `🔧 Queryable - ci: Atualizar workflow de CI`
  - `📦 Queryable - deps: Atualizar dependencias do Angular`
  - `🚀 Queryable - perf: Melhorar performance da listagem de usuarios`
  - `🔥 Queryable - remove: Remover codigo legado de autenticacao`
  - `🎨 Queryable - style: Padronizar formatacao do projeto`
  - `♻️ Queryable - refactor: Refatorando o servico de localizacao`
- Pull requests devem incluir uma descricao clara da mudanca e, para atualizacoes de diagramas, um breve resumo do que foi modificado.
